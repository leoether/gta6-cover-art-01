Sunset Cover Studio — turn your photo and a caption into multi-panel GTA-style cover art: a Vice City sunset sky with a retro slatted sun, skyline and palms, three photo panels you can crop and position, four colour grades, and PNG export in 1080 x 1080, 1080 x 1350 and 1920 x 1080. An offline static web app; all art is drawn in code, the display font is Anton under the SIL Open Font License, and the sample photos are the kit's free-to-use samples.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080, load a photo into a panel, edit the caption, and export a PNG.
